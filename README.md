# TDA NETWORK

Réseau social moderne inspiré de TikTok, Instagram et Facebook.

## 🚀 Fonctionnalités

- Authentification complète (register/login/logout)
- Profils utilisateur avec photos de couverture et bio
- Publications avec images, vidéos, carrousels
- Stories éphémères (24h)
- Système de likes et commentaires
- Followers/Following
- Groupes de discussion
- Messagerie privée
- Notifications en temps réel
- Feed personnalisé
- Mode sombre/clair
- Personnalisation des couleurs

## 🛠 Technologies

- **Frontend**: HTML, CSS, JavaScript moderne
- **Backend**: Supabase (Auth, Database, Storage)
- **Base de données**: PostgreSQL
- **Hébergement**: Vercel
- **Versionnement**: GitHub
